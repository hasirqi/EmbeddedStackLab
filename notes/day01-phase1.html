第一个 C 程序

#include <stdio.h>

int main(void)
{
    printf("Hello Linux\n");
    return 0;
}
gcc -g -Wall hello.c -o hello
./hello
Hello Linux

真实问题：复制粘贴异常

Mac → Ubuntu Terminal 粘贴时出现 ^[[200~ 等控制字符，导致命令被错误解释。

通过 which gcc 确认 GCC 实际位于 /usr/bin/gcc，因此问题不在 GCC，而在粘贴输入。
经验：出现奇怪的控制字符时，先手工输入关键命令验证，不要直接重装软件。
