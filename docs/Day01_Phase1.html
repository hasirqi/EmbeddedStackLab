int main(void)
{
    printf("Hello Linux\n");
    return 0;
}

编译

gcc -g -Wall hello.c -o hello

运行

./hello
Hello Linux

4. 今天遇到的真实问题

从 Mac 向 Ubuntu Terminal 粘贴命令时曾出现 ^[[200~ 等控制字符。

GCC 本身没有问题，which gcc 返回 /usr/bin/gcc。真正的问题是粘贴时混入了终端控制字符。

5. 第一阶段核心认识

写 C 代码
   ↓
gcc 编译
   ↓
生成 ELF 可执行文件
   ↓
Linux 启动程序
   ↓
程序执行
   ↓
终端看到输出
