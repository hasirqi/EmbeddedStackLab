学习路线

最终目标不是“看过”，而是能独立开发、读代码、定位问题并解释整个调用链。

  1. 能画出 Linux → Driver → HAL → Android Service 的调用链。
  2. 能自己写并 Debug 一个简单 Linux C/C++ 程序。
  3. 能读懂基本 Kernel Driver 的 probe / remove / ioctl。
  4. 知道 Binder / AIDL / HAL 分别解决什么问题。
  5. 遇到问题会使用 gdb / strace / dmesg / logcat 做 Layer 切分。
  6. Git 的 branch / rebase / cherry-pick / conflict / code review 不害怕。
  7. 面对几十万行代码，沿 Interface 和 Call Path 追踪，而不是试图全部读完。
